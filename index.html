Core Engineering Challenges Solved
CHALLENGE 01
Table Virtualization
Rendering thousands of biometric records caused 180ms UI frame drops. Solved by virtualizing DOM rows via MUI X-DataGrid and debouncing search query filters by 400ms.
CHALLENGE 02
Type-Safe RBAC Routing
Prevented unauthorized access across 4 user tiers by configuring TanStack Router beforeLoad auth guards and declarative <PermissionGate> UI state wrappers.
CHALLENGE 03
Client-Side Export Engine
Offloaded PDF & Excel payroll slip rendering from server queues directly to browser Web APIs using ExcelJS and jsPDF, achieving instant sub-second downloads.
